# Examples

| Folder | What it shows |
|--------|---------------|
| [`support-triage`](support-triage/) | The `verano` CLI end to end on a small app: scan the code, push it to Verano, run it on 100 labelled tickets, gate a pull request on the result. |
| [`task-types`](task-types/) | The real-model check kit: one prompt and 30–32 cases for each of the seven task types, each with a `verano.yaml` on a free local model. |
| [`near-duplicates`](near-duplicates/) | 10 planted near-copy pairs and 20 distinct tickets, used by `scripts/check_dedupe.py` to test near-duplicate removal with the real embedding model. |
