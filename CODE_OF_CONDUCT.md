# Code of conduct

Verano is for people who want to build better prompts and apps. To keep it a place where that is easy:

- Be kind and assume good intent. Disagree with an idea, not with the person.
- Give specific, useful feedback, and take it the same way.
- No harassment, insults, discrimination, or sharing someone's private information.
- Keep issues and discussions on topic, and say what you tried so others can help.

If someone breaks these rules, a maintainer may edit or remove their comments, or block them from the project.
To report a problem, use the repository's **Security** tab (Report a vulnerability) and say it is a conduct report;
only the maintainers can see it.
